# 분수교구함

분수 하나를 **막대·원·수직선**으로 함께 보는 단일 화면 분수 교구입니다.

- **카테고리**: 01. 교과 교육지원 앱
- **대상**: 초등 3~5학년 수학 수업(전자칠판 시연, 태블릿 개별 조작)
- **기술**: HTML · CSS · JavaScript (외부 라이브러리 없음)

## 실행 방법

`index.html`을 더블클릭하면 브라우저(Chrome·Edge 권장)에서 바로 열립니다. 설치나 인터넷 연결이 필요 없습니다.

온라인: https://changsubkwak.github.io/ginue-2026_02_ai_course-homework/01_교과교육지원_분수교구함/

## 할 수 있는 것

- **분수 만들기**: 분자·분모 −/+ 버튼, 자주 쓰는 분수 칩 8개, 막대나 원의 칸을 눌러 색칠
- **세 모델 함께 보기**: 막대(길이)·원(넓이)·수직선(수)이 한 분수를 동시에 보여 줌. 가분수는 모델이 2개로 늘고 대분수를 함께 표시
- **같게 쪼개기·합치기**: ×2·×3으로 칸을 쪼개도 색칠된 양이 그대로임을 보여 주고, 합치기로 약분. 과정은 동치 사슬(3/4 = 6/8 …)로 표시
- **수 표현**: 소수(= 또는 ≈)와 읽는 법(4분의 3). '예측 먼저' 수업을 위해 숨길 수 있음
- **큰 글씨**·라이트/다크 테마, 마지막 상태 자동 저장

## 사용 순서

1. 분모와 분자를 정하거나 칩을 고릅니다.
2. 세 모델과 소수·읽기가 함께 바뀌는 것을 확인합니다.
3. ×2·×3을 눌러 동치분수를 만들고, 합치기로 되돌립니다.

## 파일

```
index.html      화면
css/style.css   스타일(라이트/다크, 반응형)
js/app.js       분수 계산·SVG 그리기·상태 저장
```
