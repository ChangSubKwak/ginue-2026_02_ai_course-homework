# 분수교구함 — 분수 하나를 막대·원·수직선으로 함께 보는 단일 화면 분수 교구

**카테고리:** 01. 교과 교육지원 앱  |  **대상:** 초등 3~5학년 수학 수업의 교사(전자칠판·TV 시연)와 학생(태블릿·PC 개별 조작), 가정 복습용 학부모  |  **기술:** HTML/CSS/JS (외부 라이브러리 없음)

## 소개
분수는 초등 3~5학년에 걸쳐 반복 등장하지만 "2/4와 1/2은 다르다", "분모가 크면 더 크다" 같은 오개념이 굳어지기 쉽습니다. 칠판에 손으로 그린 막대나 원은 비율이 부정확해 '정확히 같은 양'을 설득하기 어렵습니다. 분수교구함은 분수 하나를 고르면 막대(길이)·원(넓이)·수직선(수)의 세 표상과 분수 기호·소수·읽는 법이 동시에 바뀌는 가상 교구입니다. 교사는 전자칠판에서 분모를 바꾸고 칸을 색칠하며 '같게 쪼개기'로 동치분수가 만들어지는 과정을 보여 주고, 학생은 태블릿에서 직접 조작하며 분수의 크기를 눈으로 확인합니다. 기능을 최소화한 단일 화면 앱이라 설명 없이도 1분 안에 사용법을 익힐 수 있습니다.

## 실행 방법
- `index.html`을 더블클릭하면 바로 실행됩니다(file:// 환경, 설치·서버 불필요).
- 로컬 서버로 열어도 동일하게 동작합니다. 예: `npx serve .` 또는 VS Code Live Server.
- 권장 브라우저: 최신 Chrome / Edge (터치 전자칠판·태블릿 포함). 인터넷이 없으면 Google Fonts 대신 시스템 글꼴로 자동 대체됩니다.

## 주요 기능
| 기능 | 설명 |
|---|---|
| 세 표상 동기화 교구판 | 막대·원·수직선이 한 분수를 동시에 보여 줍니다. 분모(1~12)·분자(0~분모×2)를 바꾸면 세 모델과 기호가 즉시 함께 바뀌고, 가분수면 막대·원이 2개로 늘어나며 수직선이 0~2로 확장되고 대분수(7/4 = 1 3/4)가 함께 표시됩니다 |
| 분수 입력 | 분자·분모 −/+ 버튼, 막대·원 칸 클릭(마지막 칸을 다시 누르면 하나 줄어듦), 자주 쓰는 분수 칩 8개(1/2, 1/3, 2/3, 1/4, 3/4, 2/5, 5/6, 7/4), 키보드 ←/→(분자)·↑/↓(분모) |
| 같게 쪼개기·합치기 | ×2·×3으로 모든 칸을 쪼개면(새 분할선이 주황색으로 나타나는 0.3초 애니메이션) 분자·분모가 함께 곱해져 색칠된 양은 그대로임을 보여 줍니다. 합치기(약분)는 최대공약수로 약분하며 기약분수면 비활성. 과정은 동치 사슬(3/4 = 6/8 = …, 최대 6개)에 쌓이고 항을 누르면 그 분수로 되돌아가며 '처음으로'로 사슬을 지웁니다. 분모 12를 넘는 쪼개기는 비활성 |
| 수 표현 패널 | 세로 분수 기호, 대분수(가분수일 때), 소수(유한소수면 `=`, 아니면 `≈` 셋째 자리), 읽기('4분의 3', 대분수 '1과 4분의 3' 병기). 소수·읽기는 체크박스로 숨겨 '예측 먼저' 수업에 활용 |
| 모델 표시 선택·큰 글씨 | 막대·원·수직선을 각각 켜고 끄기(최소 1개 유지). '큰 글씨'를 켜면 글꼴·버튼이 1.4배로 커지고 한 열 배치로 바뀌어 모델이 화면 폭 전체를 씁니다 |
| 설정 기억·초기화 | 분수·표시 설정·동치 사슬·큰 글씨를 localStorage에 저장해 다시 열면 복원. '처음 상태로'는 모달 확인 후 3/4·세 모델 켜짐으로 복원 |
| 도움말·테마 | `?` 버튼의 3단계 사용법 + 수업 팁 모달, 라이트/다크 테마 토글(저장값이 없으면 OS 설정을 따름), alert/confirm/prompt 미사용 |

## 화면 구성
- **헤더**: 로고·앱 이름·태그라인, 우측 툴바(큰 글씨, 테마 🌙/☀️, 도움말 ?, 처음 상태로).
- **분수 만들기(왼쪽 위 / 좁은 화면에서는 맨 위)**: 세로 분수 꼴로 배치된 분자·분모 −/+ 스테퍼, 자주 쓰는 분수 칩 8개.
- **무대(가운데)**: 수 표현 패널(기호·대분수·소수·읽기, 소수/읽기 체크박스) → 보기 토글(막대·원·수직선) → 막대·원·수직선 모델이 세로로 쌓임. 각 모델 캡션에 '4칸 중 3칸' 요약.
- **같게 쪼개기·합치기(왼쪽 아래 / 좁은 화면에서는 맨 아래)**: ×2 / ×3 / 합치기(약분) 버튼, 동치 사슬, 처음으로.
- **푸터·공통**: 푸터, 도움말 모달, 초기화 확인 모달, 우하단 토스트.

## 사용 방법
1. **분수 만들기** — 분모·분자 −/+ 버튼을 누르거나 자주 쓰는 분수 칩을 고르세요. 막대나 원의 칸을 직접 눌러 색칠해도 됩니다(마지막 칸을 다시 누르면 하나 줄어요).
2. **세 모델 함께 보기** — 막대(길이)·원(넓이)·수직선(수)과 분수 기호·소수·읽기가 동시에 바뀝니다. 분자가 분모보다 크면 막대·원이 2개가 되고 대분수가 함께 표시돼요.
3. **같게 쪼개기·합치기** — ×2, ×3을 누르면 모든 칸이 쪼개지고 색칠된 양은 그대로입니다(동치분수). 합치기(약분)는 다시 간단한 분수로 돌아가고, 과정이 동치 사슬에 쌓입니다.
- 수업 팁(동치분수 시연 순서): 분모 4, 칸을 눌러 3/4를 만든 뒤 세 모델이 같은 양임을 짚기 → "×2를 누르면 색칠된 양이 달라질까?" 예측 → ×2로 6/8이 되어도 색칠 양이 그대로임을 확인하고 사슬 '3/4 = 6/8' 읽기 → 합치기로 3/4로 복귀 → 소수·읽기 체크를 끄고 학생이 먼저 예측하게 하기.
- 전자칠판·TV에서는 '큰 글씨'를 켜고, 보기 버튼으로 모델을 하나만 남겨 집중시킬 수 있습니다.
- 키보드: ←/→ 분자, ↑/↓ 분모, Tab 이동, Enter/Space 버튼, Esc 창 닫기.

## 데이터 저장·내보내기·가져오기
- 현재 분수·표시 설정·큰 글씨·동치 사슬은 localStorage `edu.fraction-kit.v2.state`(JSON, `version: 2`)에, 테마는 `edu.fraction-kit.theme`에 저장되며 조작할 때마다 즉시 기록됩니다. 저장값은 다시 열 때 범위를 검증한 뒤 복원하고, 깨진 값은 기본값으로 대체합니다.
- localStorage를 쓸 수 없는 환경(사생활 보호 모드 등)에서는 메모리로만 동작하며 토스트로 1회 안내합니다.
- 학생 명단·학급 기록을 다루지 않는 단일 화면 교구이므로 내보내기/가져오기 기능은 두지 않았습니다. '처음 상태로'가 저장값을 기본값(3/4, 세 모델 켜짐)으로 되돌립니다.

## 샘플 데이터 안내
내장 데이터는 기본 분수 3/4와 자주 쓰는 분수 칩 8개뿐입니다. 학교명·학급·학생 이름은 사용하지 않으며, 저장되는 값도 분수와 표시 설정뿐입니다.

## 기술적 특징
- **SVG 세 표상 실시간 동기화**: 상태 `{n, d, show, big, chain}` 하나를 `render()`가 막대·원·수직선 SVG 문자열로 매번 다시 그립니다(viewBox 1000 단위 → 화면 폭에 비례). 막대는 가분수일 때 세로로 2줄, 원은 가로로 2개, 수직선은 0~2로 확장되며 칸마다 `data-i`를 두어 클릭 한 번으로 분자를 바꿉니다. 모든 색은 CSS 토큰이라 다크 모드에서도 색칠·분할선이 그대로 보입니다.
- **같게 쪼개기 애니메이션**: ×k 직후 렌더에서 `j % (d/이전 분모) !== 0`인 분할선에 `.new`를, 합치기 직후에는 사라지는 선에 `.ghost`를 붙여 CSS 키프레임(0.3초, 주황 강조)으로 나타나고 사라지게 합니다. `prefers-reduced-motion`에서는 즉시 완료됩니다.
- **정수 연산 분수 유틸**: 약분한 분모의 소인수가 2·5뿐이면 유한소수(`=`), 아니면 `≈` 셋째 자리 반올림. 읽기는 '분모분의 분자', 가분수는 대분수 읽기를 병기합니다.

## 제한 사항 및 향후 개선
- 사용자 요청으로 원래 설계(6개 탭: 교구판·비교통분·덧셈뺄셈·탐구카드·보관함·활동지)에서 교구판 하나만 남긴 단순화 버전입니다. 비교·통분, 덧셈·뺄셈 시각화, 탐구 카드, 장면 보관함, 활동지 인쇄, 펜 주석, 되돌리기, PNG 저장은 범위 밖입니다.
- 분모는 12까지, 분자는 분모의 2배까지만 다룹니다(초등 교과 범위에 맞춘 상한).
- 막대·원 칸은 마우스·터치로만 직접 색칠할 수 있고, 키보드 사용자는 −/+ 버튼이나 화살표 키로 같은 조작을 합니다.
- 향후: 두 분수를 나란히 놓는 비교 모드, 활동지 인쇄를 선택 기능으로 되살리기.

## 바이브코딩 개발 과정
1. 스펙 JSON(기능 7개·수용 기준 15개·범위 밖 목록)과 5개 앱 공통 규약(파일 구조·테마 토큰·storage 래퍼·모달/토스트)을 AI에게 입력으로 주었습니다.
2. "기능이 너무 많으니 교구판 하나만 남겨 심플하게"라는 요청에 따라 기존 6탭 구현을 보관 폴더로 옮기고, 분수 유틸과 SVG 렌더 아이디어만 참고해 빈 폴더에서 다시 작성했습니다.
3. 첫 프롬프트로 index.html·style.css·app.js 골격(상태 → 렌더 단방향, 이벤트 위임, `window.__app` 디버그 API)을 생성했습니다.
4. 정적 점검 스크립트(alert 금지·다크 토큰·safe-area 등)와 Playwright 스모크(콘솔 오류·가로 스크롤·3개 뷰 스크린샷)를 돌려 문제 0건을 확인했습니다.
5. 수용 기준 15개를 Playwright 테스트 모듈로 옮겨 모두 통과시켰고, 스크린샷을 보며 막대 높이·기호 크기·모바일 라벨 크기를 조정했습니다.
6. 마지막으로 모델 캡션 요약, 동치 사슬 항 클릭, 화살표 키 단축키처럼 수업에 바로 도움이 되는 작은 개선만 더했습니다.
