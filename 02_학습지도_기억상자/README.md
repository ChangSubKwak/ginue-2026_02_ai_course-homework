# 기억상자

외울 것과 틀린 문제를 카드로 만들어 **잊기 직전에 다시 복습**하게 하는 간격 반복 복습·오답 노트입니다.

- **카테고리**: 02. 학습지도용 앱
- **대상**: 초등 3~6학년 학생(자기주도 복습), 담임·교과 교사(학급 오답 집계)
- **기술**: HTML · CSS · JavaScript (외부 라이브러리 없음)

## 실행 방법

`index.html`을 더블클릭하면 브라우저(Chrome·Edge 권장)에서 바로 열립니다. 설치나 인터넷 연결이 필요 없습니다.

온라인: https://changsubkwak.github.io/ginue-2026_02_ai_course-homework/02_학습지도_기억상자/

## 할 수 있는 것

- **카드 등록**: 암기 카드와 오답 카드(내 답·틀린 이유 태그). 교사가 준 CSV로 한꺼번에 등록
- **라이트너 상자 복습**: 상자 1~5, 복습 간격 1·2·4·7·15일. 오늘 복습할 카드만 자동으로 골라 줌
- **확신도 체크**: 뒤집기 전에 '모름/애매/확실'을 골라 아는 것과 모르는 것을 구별(메타인지)
- **기록 대시보드**: 잔디 달력, 상자 분포, 틀린 이유 도넛, 망각 예측 그래프
- **시험 D-Day**: 시험일까지 복습을 고르게 나눠 계획
- **인쇄**: 양면 암기카드, 다시풀기 학습지
- **교사 모드**: 학생들이 낸 복습 요약 파일을 모아 학급 공통 오답 단원·원인 집계

## 사용 순서

1. 카드 탭에서 덱을 만들고 카드를 넣습니다.
2. 홈의 "오늘 복습"을 누르고, 확신도 → 뒤집기 → 맞음/틀림 순으로 복습합니다.
3. 맞히면 다음 상자로, 틀리면 1상자로 돌아갑니다.
4. 기록 탭에서 내 복습 습관과 자주 틀리는 이유를 확인합니다.

단축키(복습 중): 1·2·3 확신도, Space 뒤집기, ← 틀림, → 맞음, Esc 종료

## 파일

```
index.html      화면
css/style.css   스타일(라이트/다크, 반응형, 인쇄)
js/util.js      날짜·CSV·모달·토스트 공통 함수
js/data.js      샘플 데이터
js/app.js       상자 스케줄러·복습 세션·차트·저장
```

## 참고

- 내장 학생(가온초등학교 5학년 2반 김하늘·이도윤 등)은 모두 가상 인물입니다.
- 데이터는 이 브라우저(localStorage)에만 저장되며, 설정 탭에서 JSON으로 백업·복원할 수 있습니다.
