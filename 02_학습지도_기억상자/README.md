# 기억상자 — 외울 것과 틀린 것을 상자에 넣고, 잊기 직전에 다시 만나는 초등 간격 반복 복습·오답 노트

**카테고리:** 02. 학습지도용 앱  |  **대상:** 초등 3~6학년 학생(자기주도 복습), 담임·교과 교사(학급 단어장 배부·오답 집계), 학부모(기록·주간 리포트)  |  **기술:** HTML/CSS/JS (외부 라이브러리 없음)

## 소개
초등학생은 받아쓰기 낱말·영어 단어·사회과학 용어·수학 오답을 시험 전날 몰아서 보고 금방 잊고, 오답노트는 베껴 쓰는 데서 끝나 같은 이유로 다시 틀립니다. 기억상자는 카드를 **라이트너 5단계 상자**에 넣고 "오늘 복습할 카드"만 자동으로 골라 주어 간격 반복과 인출 연습을 아이 눈높이의 "상자 옮기기"로 체화시킵니다. 뒤집기 전에 **확신도**를 고르게 하여 "아는 것과 모르는 것"을 구별하는 메타인지를 훈련하고, 오답 카드는 **틀린 원인 태그**를 붙여 자기 실수 패턴을 도넛 차트로 발견하게 합니다. 교사는 학급 단어장 CSV를 배부하고 학생들의 복습 요약 파일을 모아 **학급 공통 오답 단원과 원인**을 집계할 수 있습니다. 모든 데이터는 기기(localStorage)에만 저장되며 JSON/CSV로 옮깁니다.

## 실행 방법
- `index.html`을 더블클릭하면 바로 열립니다(file:// 환경, 설치·서버·인터넷 불필요. 인터넷이 있으면 Google Fonts의 Gaegu·Nanum Gothic이 적용되고, 없으면 시스템 글꼴로 동작).
- 로컬 서버로 열어도 됩니다: 폴더에서 `python -m http.server 8080` → `http://localhost:8080/`.
- 권장 브라우저: 최신 Chrome / Edge (태블릿·크롬북 터치 지원).

## 화면 구성
- **홈(오늘)**: D-Day 배너, "오늘 복습 N장(밀림 M장)" 버튼(또는 이어서 하기/미리 복습), 하루 목표 진행 바, 스트릭 불꽃, 상자 5개 그림(누르면 그 상자 카드 목록), 빠른 추가(+) 버튼.
- **복습 세션**: 진행 바, 상단 미니 상자 5개, 앞/뒷면 카드, 확신도 3버튼 → 뒤집기 → 힌트 보기 · 틀렸어요/맞았어요, 오답 원인 패널, 단축키 안내, 끝나면 요약 모달.
- **카드**: 덱 목록 → 덱 상세(CSV 드롭존, 내보내기, 수정·삭제, 지금 복습) → 검색·상자/유형 필터·정렬이 있는 카드 목록, 카드 모달.
- **기록**: 요약 카드 4개, 잔디 달력, 상자 분포, 원인 도넛, 망각 예측, 되새김 한 줄 목록, 이번 주 리포트.
- **시험**: 시험 목록(D-n, 포함 덱, 남은 카드), 계획 달력, 다시 생성·삭제, 시험 끝 상태.
- **인쇄**: 덱·상자 범위·유형 선택, 레이아웃(양면 카드/학습지), 옵션, 미리보기 → 인쇄.
- **교사**(교사 모드): 드롭존, 학생 목록, 복습 포인트 카드, 단원×원인 표, 집중 지도 목록, CSV 내보내기.
- **설정**: 프로필 관리, 하루 목표, 간격표, 교사 모드·애니메이션 줄이기, 백업/복원/요약 내보내기/CSV 템플릿, 샘플 다시 넣기, 데이터 삭제, 저장 용량.

## 사용 방법
1. **카드 넣기** — 카드 탭에서 덱을 만들고 "+ 카드"로 외울 것(암기)이나 틀린 것(오답)을 적습니다. 교사가 준 CSV를 끌어 놓아도 됩니다.
2. **오늘 복습** — 홈의 "오늘 복습 N장"을 누르면 잊기 직전인 카드만 골라 보여 줍니다.
3. **확신도 → 뒤집기 → 채점** — 뒤집기 전에 확실해요/애매해요/모르겠어요를 고르고, 뒤집어 정답을 본 뒤 맞았어요/틀렸어요를 누릅니다. 맞히면 다음 상자로, 틀리면 1상자로 갑니다.
4. **되새김** — 다 끝나면 4분면 표와 코칭 한 줄이 나옵니다. "오늘 가장 헷갈린 것 한 줄"을 적어 둡니다.
5. **기록·시험·인쇄** — 기록 탭에서 잔디 달력·원인 도넛·망각 예측을 보고, 시험 탭에서 D-Day 계획을, 인쇄 탭에서 암기카드·학습지를 뽑습니다.
6. **교사** — 설정에서 교사 모드를 켜고 학생들의 "복습 요약 JSON"을 모으면 학급 공통 오답을 집계합니다.

팁: 상자 간격은 1·2·4·7·15일, 5상자에서 확실히 맞히면 30일 뒤(숙달 ★). 단축키(복습 중): 1/2/3 확신도, Space 뒤집기, ← 틀림, → 맞음, Esc 종료. 뒤집힌 카드는 좌우로 밀어도 됩니다.

## 기술적 특징
- **라이트너 간격 반복 스케줄러**: `INTERVAL={1:1,2:2,3:4,4:7,5:15}`. 틀림 → 1상자·내일, 맞음+확실 → 다음 상자(5상자면 30일·숙달), 맞음+애매 → 제자리, 맞음+모름 → 내일(승급 보류). 날짜는 `YYYY-MM-DD` 문자열을 로컬 구성 요소로 더하고 문자열 비교로 정렬해 DST·시간대 문제가 없습니다. 시험 D-Day는 대상 카드를 (상자, 복습일)순으로 늘어놓고 `i mod D`일에 배치하며 뒤로 미루지는 않습니다. 망각 예측은 "오늘 큐를 모두 확실히 맞힌다"는 가정으로 7일간 밀릴 카드 수를 두 선으로 비교합니다.
- **직접 그린 SVG 차트**: 잔디 달력(84일 × 5단계 색), 상자 분포 막대, 원인 도넛(원호 path 계산), 망각 예측 선 그래프를 문자열 템플릿으로 생성하고 `viewBox`로 반응형, 색은 CSS 토큰(`--grass-*`, `--chart-*`)이라 다크 모드에서도 읽힙니다.
- **메타인지 피드백**: 확신도×결과 4분면(알고 맞힘/운 좋게 맞힘/착각/모르는 걸 알았어)과 규칙 6개(R1~R6)로 고르는 코칭 문장, 오답 원인 `failReasons` 최근 3회 동일 시 "같은 이유로 3번" 배지.
- 상태 → 렌더 단방향(`state` + 화면별 `views.*`), `data-action` 이벤트 위임, 공용 `showModal`(Promise·포커스 트랩)·`showToast`, CSV 상태기계 파서, Pointer Events 스와이프·캔버스, `@media print` 양면 정렬.
- 테스트 편의를 위해 `window.__app = { version, getState(), actions:{startSession, grade, switchProfile, importCsvText, …} }`를 노출합니다(읽기 전용 스냅샷 + 주요 액션).

## 제한 사항 및 향후 개선
- 카드 간 드래그로 상자를 바꾸는 수동 조정(nice)은 구현하지 않았습니다(카드 수정 모달과 복습으로 대체).
- 카드별 난이도 계수(SM-2 등)는 의도적으로 제외하고 고정 간격표만 사용합니다.
- 서버 동기화·로그인이 없어 기기 간 이동은 JSON 백업으로만 가능합니다. 사진 첨부 대신 손그림 캔버스만 지원합니다.
- 향후: 덱 공유 QR, 음성 읽기(TTS), 학급 단어장 배부 링크, 되새김 한 줄의 교사 코멘트.

## 바이브코딩 개발 과정
1. 과제 카테고리(학습지도)에 맞는 앱 아이디어 6개를 AI에게 제안받아 심사 기준(가치·실용·구현·차별·적합)으로 채점하고, "기억상자" 골격에 다른 안의 4분면 피드백·원인 태그·교사 집계를 합쳐 스펙(JSON)을 확정했습니다.
2. 5개 앱 공통 규약(파일 구조, 테마 토큰 3블록, alert 금지, localStorage 래퍼, 샘플 데이터 내장)을 먼저 문서화하고, 스펙과 함께 빌드 프롬프트로 전달했습니다.
3. AI가 util(날짜·CSV·모달) → data(샘플 생성기) → index/css → app(스케줄러·세션·차트) 순으로 작성했고, 샘플 생성기는 "오늘 복습 11장(밀림 3장)·스트릭 6·D-12"가 항상 재현되도록 시험 재분배 후 큐를 보정하는 로직을 넣었습니다.
4. 정적 점검 스크립트(규약 위반 탐지)와 Playwright 스모크 점검(콘솔 오류·가로 스크롤·3개 뷰 스크린샷)을 돌려 문제 0건을 확인했습니다.
5. 스펙의 수용 기준 15개를 Playwright 테스트 모듈로 옮겨 자동 확인했고, 그 과정에서 탭 클릭 미배선, 스트릭 계산용 샘플 날짜 오류 등을 찾아 고쳤습니다.
6. 스크린샷을 눈으로 보며 라이트/다크/400px 레이아웃을 다듬고 README를 정리했습니다.
