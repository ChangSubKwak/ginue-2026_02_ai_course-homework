# 분수교구함 — 막대·원·수직선이 한 몸처럼 움직이는 분수 조작 교구

**카테고리:** 01. 교과 교육지원 앱  |  **대상:** 초등 3~5학년 수학 교사(전자칠판 시연)·3~6학년 학생(태블릿 조작)·기초학력 보충지도  |  **기술:** HTML/CSS/JS (외부 라이브러리 없음)

## 소개
분수는 3-1부터 5-1까지 매 학년 등장하는 누적 개념이지만 "1/3이 1/2보다 크다", "분자끼리·분모끼리 더한다", "2/4와 1/2은 다르다" 같은 오개념이 가장 많이 굳어지는 영역입니다. 교실의 실물 분수 막대는 한두 세트뿐이고, 칠판에 손으로 그린 막대·원은 비율이 부정확해 '정확히 같은 크기'를 설득하기 어렵습니다. 분수교구함은 길이(막대)·넓이(원)·수(수직선) 세 표상과 분수 기호를 실시간으로 동기화한 가상 교구로, 등분을 바꾸고 색칠하고 쪼개고 겹치는 조작의 결과가 즉시 기호로 나타나 "왜 그렇게 되는지"를 눈으로 확인시킵니다. 교사는 전자칠판에서 동치분수·통분·덧셈뺄셈 과정을 애니메이션으로 시연하고, 예측-확인 탐구 카드로 학급 예측 분포를 모아 토의를 이끌며, 수업 장면을 저장·공유하고 같은 장면을 A4 활동지로 바로 인쇄할 수 있습니다.

## 실행 방법
- `index.html`을 더블클릭하면 바로 실행됩니다(file:// 환경, 설치·서버 불필요).
- 로컬 서버로 열어도 동일하게 동작합니다. 예: `npx serve .` 또는 VS Code Live Server.
- 권장 브라우저: 최신 Chrome / Edge (터치 전자칠판·태블릿 포함). 인터넷이 없으면 Google Fonts 대신 시스템 글꼴로 자동 대체됩니다.

## 주요 기능
| 기능 | 설명 |
|---|---|
| 3표상 연동 교구판 | 분모 슬라이더(1~24), 칸 클릭·드래그 색칠, 원 조각 클릭(12등분까지), 수직선 점 드래그(1/d 스냅). 어느 모델을 조작해도 나머지 모델과 기호 패널(세로 분수·대분수·소수·읽기·약분 힌트)이 같은 프레임에 갱신. 가분수는 막대·원 2~3개로 자동 확장 |
| 같게 쪼개기·합치기 | ×2·×3으로 동치분수, 합치기(약분)로 기약분수. 새 분할선이 투명→선명(또는 반대)으로 나타나는 rAF 애니메이션, 식 영역에 `1/2 = 2/4 = 6/12` 사슬과 ×2·÷2 라벨 누적 |
| 비교·통분 보드 | A(파랑)·B(주황) 막대, 칩·키패드 입력, 겹쳐 보기(반투명 + 차이 빗금 + 차이 분수), 같은 분모로 맞추기 3단계(A 재분할 → B 재분할 → 비교) 자동 재생 |
| 덧셈·뺄셈 4단계 | 통분 → 합치기/지우기(B 칸 그룹이 미끄러져 결과 막대로 이동) → 결과(대분수 변환, 단위 경계 번쩍임) → 약분. 뺄셈 A<B면 자리 바꾸기 모달. 교사 모드 '오개념 거울'로 분자끼리·분모끼리 계산과의 차이 표시 |
| 예측-확인 탐구 카드 | 내장 24장(학년별 8장)·세트 2개. 선택지로 예측 → 확인하면 커튼이 내려가며 단계 애니메이션 자동 재생 → 초록/주황 메시지 + 교사용 해설. 학급 집계(손든 수 → 백분율 막대, 정답 강조). 카드 편집·새 카드·삭제·순서·세트 저장 |
| 장면 보관함 | 이름·학년·단원·메모(발문)와 함께 현재 작업 상태 저장(최대 200개). 썸네일 그리드, 검색·학년 필터, 불러오기·이름 바꾸기·복제·삭제, JSON 내보내기/가져오기(검증·원자적 병합), 샘플 복원 |
| 활동지 A4 인쇄 | 카드·장면·빠른 문항으로 색칠하기/분수 쓰기/수직선/크기 비교/덧셈·뺄셈 문항 구성, 쪽당 6문항 2열 미리보기, 정답지 자동 계산, 흑백 빗금 옵션, `window.print()` |
| 전자칠판 도구 | 칠판 모드(1.5배 글꼴·56px 버튼·고대비), 전체화면(API 실패 시 CSS 대체), 커튼, 펜 주석 Canvas(빨강·파랑·형광·지우개), 되돌리기/다시하기 50단계(Ctrl+Z/Y), 교사·학생 모드, 학년 프리셋, PNG 그림 저장, 라이트/다크 테마 |

## 화면 구성
- **앱 셸**: 로고(도움말)·태그라인, 전역 도구(되돌리기·다시하기·장면 저장·펜·커튼·칠판·전체화면·더 보기[교사 모드·학년·PNG·내보내기·샘플 복원]·테마·도움말), 탭 6개, 교사 메모 패널, 저장 불가 배너, 토스트·모달.
- **교구판**: 좌측 제어 패널(분모 슬라이더·분자 ±·×2/×3/합치기/사슬 지우기·수직선 범위·모델 표시·소수·어림해서 찍기), 중앙 막대·원·수직선, 하단 기호 패널과 동치 사슬 식. 400px에서는 모델 탭 전환 + 하단 시트 패널.
- **비교·통분**: A/B 입력 블록, 두 막대(겹쳐 보기), 수직선 두 점, 단계 표시기와 버튼(같은 분모로 맞추기·다음·자동 재생·처음으로·겹쳐 보기·바꾸기·초기화), 결과 식.
- **덧셈·뺄셈**: A/B 입력 + 연산 토글, 막대 A·B·결과(·오개념 거울), 4단계 표시기, 식 전개, 거울 라벨.
- **탐구 카드**: 세트 드롭다운·학년 칩·검색·카드 목록(체크·순서·편집·삭제), 카드 뷰(질문·선택지·예측 배지·확인·메시지·해설·이전/다음), 학급 집계, 연동 작업판(커튼).
- **장면 보관함**: 검색·학년 필터·내보내기·선택만 내보내기·샘플 복원·가져오기 드롭존, 장면 카드 그리드.
- **활동지**: 문항 출처(카드·장면·빠른 문항), 문항 목록(↑↓·삭제·섞기·모두 지우기), 설정(제목·빈칸·정답지·흑백·모델), A4 미리보기, 인쇄.
- **분수 키패드 모달(공통)**: 자연수·분자·분모 필드, 숫자 패드, 빠른 칩 12개, 실시간 미리보기와 유효성 메시지.

## 사용 방법
1. **교구판 조작**: 분모 슬라이더를 움직이면 막대·원·수직선이 함께 다시 그려집니다. 막대 칸이나 원 조각을 누르거나 드래그해 색칠하고, 수직선의 점을 끌어 분수를 바꿔 보세요.
2. **같게 쪼개기·합치기**: ×2, ×3을 누르면 색칠된 양은 그대로인 채 분할선만 늘어나고(동치분수), 합치기(약분)를 누르면 분할선이 사라집니다. 식 영역에 1/2 = 2/4 = 6/12 사슬이 쌓입니다.
3. **비교·통분**: 두 분수를 칩이나 키패드로 넣고 겹쳐 보기로 차이를 확인한 뒤, 같은 분모로 맞추기 → 다음을 눌러 통분 과정을 단계별로 보여 주세요. 덧셈·뺄셈 탭은 통분 → 합치기/지우기 → 결과 → 약분 4단계입니다.
4. **탐구 카드**: 카드를 고르면 결과가 커튼으로 가려진 채 교구가 준비됩니다. 학생 예측을 선택지로 받고, 교사 모드에서는 학급 집계에 손든 수를 입력한 뒤 확인을 눌러 애니메이션으로 정답을 드러내세요.
5. **장면 저장·활동지**: 장면 저장으로 현재 화면을 보관함에 넣고 JSON으로 내보내 공유할 수 있습니다. 활동지 탭에서 카드·장면·빠른 문항을 골라 A4로 인쇄(정답지 포함 가능)하세요.
- 팁: 칠판 모드 + 전체화면은 전자칠판용, 교사 모드를 끄면 해설·집계·편집이 숨겨진 학생용 화면이 됩니다.
- 팁: 비교·통분 탭에서 바꾼 A·B는 덧셈·뺄셈 탭으로 처음 넘어갈 때 한 번만 이어집니다(연산 탭에서 직접 입력한 값이나 불러온 장면은 덮어쓰지 않으며, 이어 붙이기는 Ctrl+Z로 되돌릴 수 있습니다). 교사 메모 패널은 장면이 속한 탭에서만 보이고, 그림 저장(PNG)은 교구판·비교·덧셈뺄셈 탭에서 동작합니다.
- 단축키: Ctrl+Z / Ctrl+Y(되돌리기·다시하기), Esc(모달 닫기·전체화면 대체 해제), Ctrl+P(활동지 인쇄).

## 데이터 저장·내보내기·가져오기
- 모든 데이터는 브라우저 localStorage(`edu.fraction-kit.v1.*`: scenes, cards, cardSets, tally, settings, workspace, meta)에 저장되며, 작업 상태는 조작 후 300ms 디바운스로 저장되어 새로고침 시 마지막 탭·분수·단계·활동지 구성이 복원됩니다. 키 접두사는 5개 앱 공통 규약(`edu.<slug>.`)을 따릅니다(스펙 초안의 `fractionKit.v1.*`와 다름).
- 가져오기 시 id는 영문·숫자·`-`·`_`(40자 이하)만 허용하고 그 외는 새 id로 바꾸며, 동치 사슬 라벨은 `×k`/`÷p` 형식만 수용합니다. 내장 id가 아닌 항목의 `builtin` 플래그는 해제되어 샘플 복원과 어긋나지 않습니다.
- localStorage를 쓸 수 없는 환경(사생활 모드 등)에서는 메모리로만 동작하며 상단에 "저장이 꺼져 있어요. JSON 내보내기로 보관하세요" 배너가 1회 표시됩니다.
- **내보내기**: 보관함 또는 더 보기 메뉴의 내보내기 → `fraction-kit-YYYYMMDD.json`(장면·카드·세트 전체). 체크한 장면만 내보내기도 가능합니다.
- **가져오기**: 보관함 드롭존에 파일을 끌어 넣거나 파일 선택. 파일 크기(5MB)·`app: "fraction-kit"`·분수 범위·선택지/정답 인덱스를 검증하고, 같은 id는 내용이 같으면 건너뛰고 다르면 새 id를 부여해 병합합니다. 결과는 토스트와(건너뜀이 있으면) 사유 목록 모달로 안내합니다.
- **샘플 복원**: 내장 장면 12개·카드 24장·세트 2개만 원본으로 되살리고 사용자가 만든 항목은 유지합니다.

## 샘플 데이터 안내
내장 데이터는 모두 가상의 샘플입니다. 학급 집계 예시 라벨 '가온초 5-2 예시'는 가상의 '가온초등학교 5학년 2반'을 가리키며, 활동지 머리글의 학교·학년·반·이름은 빈칸으로 인쇄되고 학생 이름은 저장하지 않습니다(집계는 익명 손든 수만 다룹니다). 내장 장면 12개(3-1 피자 나누기 ~ 6-1 분수와 소수 수직선), 탐구 카드 24장(3·4·5학년 각 8장), 세트 2개('5-1 약분과 통분 도입', '4-2 분수의 덧셈과 뺄셈 1차시'), 활동지 초기 문항 8개가 첫 실행 시 자동 주입됩니다.

## 기술적 특징
- **SVG 3표상 실시간 동기화 + rAF 분할선 애니메이션**: 모든 모델은 `viewBox 1000×h`의 SVG를 상태에서 전체 재생성(createElementNS)하는 단방향 렌더이며, 쪼개기·합치기·통분 시에는 새로 생기거나 사라지는 분할선만 `.new`/`.ghost`로 표시해 `requestAnimationFrame`(easeOutCubic, 400ms)으로 opacity를 보간합니다. 덧셈의 B 칸 이동은 `<g transform>` 보간, 진행 중 새 입력이 오면 `finishAll()`로 즉시 완료 후 처리해 겹침을 막습니다. `prefers-reduced-motion`이면 모든 duration이 0입니다.
- **정수 산술**: 비교·차이는 교차곱, 소수 표기는 먼저 약분한 뒤 분모의 2·5 지수로 10^k 정수 스케일을 만들어 유한소수를 정확히 출력(3/8 → 0.375, 6/12 → 0.5)하고 그 외는 ≈0.333으로 표시합니다. 포인터 이벤트(마우스·터치·펜 통일, setPointerCapture, touch-action:none)로 칸 드래그 색칠과 수직선 스냅(round 후 clamp)을 처리합니다.
- 테스트 용이성을 위해 `window.__app = { version, getState(), actions: {...} }`를 노출합니다(읽기 전용 상태 스냅샷 + 주요 액션: setTab, kitSetD/N, kitSplit/Merge, compareSet/Next, arithSet/Next/Mirror, undo/redo, saveScene/loadScene, importJson/exportJson, resetSamples, selectCard/predict/confirmCard/setTally 등).

## 제한 사항 및 향후 개선
- 분수의 곱셈·나눗셈, 비율·백분율, 소수끼리의 연산은 범위 밖입니다. 분모는 교구판 24, 비교·연산 12까지이며 분자는 3×분모(수직선 0~3)까지입니다.
- 원 모델은 12등분까지만 직접 조작할 수 있고, 펜 주석은 저장되지 않습니다(탭 전환·장면 불러오기 시 지워짐).
- 학생 개인별 기록·CSV·서버 공유는 제공하지 않으며(JSON 파일 교환으로 대체), PDF는 브라우저 인쇄의 'PDF로 저장'을 이용합니다.
- 칠판 모드에서 제어 패널은 보조 행(수직선 범위·모델 표시)만 접고 일반 패널(240px)을 유지합니다(스펙의 '좌측 세로 아이콘 바'는 미구현). 400px에서는 전역 도구가 두 줄로 줄바꿈되고 '더 보기' 메뉴에는 교사 모드·학년·PNG·내보내기·샘플 복원만 들어갑니다.
- 애니메이션 줄이기는 OS의 '동작 줄이기' 설정을 따르며 앱 안에 별도 토글은 없습니다. 내장 데이터 버전이 올라가도 자동 안내 없이 '샘플 복원'으로 수동 갱신합니다. 분모가 같은 두 분수는 통분 단계를 건너뛰고 비교 식을 한 번만('2/5 < 4/5') 표시합니다.
- 향후: 조각을 떼어 자유 배치하는 모드, 분수 곱셈 넓이 모델, 장면에 펜 주석 포함 저장, 음성 발문 안내를 검토할 수 있습니다.

## 바이브코딩 개발 과정
1. 과제 카테고리(교과 교육지원)에 맞는 앱 아이디어를 AI와 함께 6개 제안받고, 교육적 가치·현장 실용성·구현 가능성·시연 임팩트·적합성 기준으로 채점해 분수 계열 3안을 합친 '분수교구함'을 확정했습니다.
2. 기능(must/should/nice)·화면·데이터 모델·알고리즘·수용 기준 17개를 담은 구현 스펙과 5개 앱 공통 규약(file:// 실행, 외부 라이브러리 금지, 테마 토큰, alert 금지, 저장 래퍼)을 먼저 작성해 프롬프트로 전달했습니다.
3. AI가 data.js(샘플) → fraction.js(수 유틸) → render.js(SVG·애니메이션) → ui.js(모달·키패드) → app.js(상태·교구판·비교·연산) → cards.js → scenes.js(보관함·활동지) → style.css 순으로 모듈을 생성했습니다.
4. 정적 점검(lint)으로 규약 위반(함수명 `confirm` 등)을 잡고, Playwright + Edge로 콘솔 오류·가로 스크롤·3개 뷰 스크린샷을 확인한 뒤 모바일 하단 시트 높이 버그(sticky top 잔존)와 원 테두리 클래스명을 수정했습니다.
5. 수용 기준 17개를 브라우저 자동 테스트(76개 체크)로 하나씩 검증하며 되돌리기 단축키가 슬라이더 포커스에서 막히던 문제, 키패드의 기존 값 덮어쓰기 UX를 고쳤고, should 기능(어림 찍기·카드 편집·세트·학년 프리셋·샘플 복원·자동 재생)도 추가 테스트로 확인했습니다.
6. 마지막으로 README와 도움말 모달 내용을 맞추고 빌드 보고서를 남겼습니다.
7. 검증 1라운드(기능 테스트·코드 리뷰·UX 리뷰)에서 나온 결함 — 가져오기 JSON의 id·사슬 라벨 XSS, 학급 집계 입력의 자릿수 역전, 비교→연산 탭의 A·B 덮어쓰기, 다크 테마에서 칠판 팔레트 미적용, 뺄셈 애니메이션 중 되돌리기 불일치, 읽기 어려운 SVG 라벨과 세로로 쌓인 동치 사슬, 6/12의 '≈0.500' 표기 등 — 을 수정하고 기존 테스트 모듈 10개를 모두 재실행해 통과를 확인했습니다.
