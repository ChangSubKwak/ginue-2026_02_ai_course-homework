# 특별실지기

과학실·강당·컴퓨터실과 태블릿 세트 같은 **학교 공유 자원을 주간 시간표 격자에서 예약**하고, 이중 예약을 자동으로 막아 주는 예약판입니다.

- **카테고리**: 04. 학교 행정 지원 앱
- **대상**: 특별실·기자재 담당 교사, 예약하는 담임·교과 교사, 운영 실적 보고 담당자
- **기술**: HTML · CSS · JavaScript (외부 라이브러리 없음)

## 실행 방법

`index.html`을 더블클릭하면 브라우저(Chrome·Edge 권장)에서 바로 열립니다. 설치나 인터넷 연결이 필요 없습니다.

온라인: https://changsubkwak.github.io/ginue-2026_02_ai_course-homework/04_행정지원_특별실지기/

## 할 수 있는 것

- **주간 예약판**: 요일×교시 격자에서 빈 칸을 누르거나 드래그해 예약
- **충돌 자동 검사**: 겹치는 예약·휴업일·학교 행사·수량 부족을 저장 전에 알려 주고, 대신 쓸 수 있는 시간·장소를 추천
- **수량형 기자재**: 태블릿 세트처럼 여러 개인 물품은 남은 수량으로 관리
- **학사일정 연동**: 휴업일·행사를 등록하면 해당 시간 예약이 자동으로 막힘
- **정기 예약**: "매주 목 1~2교시" 같은 반복 예약을 한 번에 생성
- **인쇄**: 교무실 게시용 주간 이용 현황표(A4 가로, 결재란 포함)
- **통계·보고**: 자원별 가동률, 학급별 이용 형평성 히트맵, 운영 실적 보고서 인쇄

## 사용 순서

1. 예약판 위쪽에서 특별실이나 기자재를 고르고 주를 이동합니다.
2. 빈 칸을 눌러 예약합니다. 겹치면 빨간 안내와 대안이 나옵니다.
3. 학사일정 탭에 휴업일·행사를 등록합니다.
4. 통계 탭에서 이용 현황을 보고, 예약판에서 주간 현황표를 인쇄합니다.

## 파일

```
index.html      화면 뼈대
css/style.css   스타일(라이트/다크, 반응형, 인쇄)
js/data.js      샘플 데이터
js/core.js      저장·충돌 검사·통계 계산
js/board.js     예약판 격자·예약 모달·정기 예약
js/views.js     학사일정·자원 관리·통계·설정 화면
```

## 참고

- 내장 데이터(경인초등학교 2026학년도 2학기, 자원 10개, 학급·교사 명단)는 모두 가상입니다.
- 데이터는 이 브라우저(localStorage)에만 저장되며, 설정 탭에서 JSON·CSV로 내보내 다른 PC로 옮길 수 있습니다.
