# 특별실지기 — 과학실·강당·컴퓨터실과 태블릿 세트까지, 학교 공유 자원을 주간 교시 격자에서 드래그로 예약하고 이중 예약을 즉시 잡아내는 학교 공유 자원 예약판

**카테고리:** 04. 학교 행정 지원 앱  |  **대상:** 특별실·기자재 관리 담당 교사(관리자), 특별실을 예약하는 담임·교과 전담 교사(예약자), 운영 실적을 보고하는 교무행정 담당자  |  **기술:** HTML/CSS/JS (외부 라이브러리 없음)

## 소개
초등학교의 특별실·기자재 예약은 교무실 화이트보드, 종이 대장, 메신저 공지로 이루어져 같은 교시에 두 학급이 겹치거나 운동회·학예회 날에도 예약이 잡히는 실수가 반복되고, 태블릿 세트처럼 수량이 있는 기자재는 남은 수량을 아무도 모릅니다. 학기말 '특별실 운영 실적' 보고는 종이표를 세어 엑셀로 옮기는 수작업이며, 어떤 학급은 실험실을 매주 쓰고 어떤 학급은 학기에 한두 번만 쓰는 격차도 드러나지 않습니다. 특별실지기는 요일×교시 격자 위에서 자원별 예약을 드래그로 등록하고, 저장 전에 이중 예약·휴업일·행사 차단·수량 부족을 자동으로 검사해 대안을 제안합니다. 학사일정 등록이 곧바로 예약 차단으로 이어지고, 정기 예약 일괄 생성, 교무실 게시용 주간 이용 현황표(A4 가로·결재란), 운영 실적 보고서와 학급별 이용 형평성 히트맵을 자동 산출합니다. 모든 데이터는 브라우저(localStorage)와 JSON 파일로 보관·인계합니다.

## 실행 방법
- `index.html`을 더블클릭하면 바로 실행됩니다(파일 경로 `file://`에서 동작, 설치·서버·로그인 없음).
- 로컬 서버를 쓰려면 폴더에서 `python -m http.server 8000` 후 `http://localhost:8000/` 접속.
- 권장 브라우저: 최신 Chrome / Edge. 인터넷이 없어도 동작하며(구글 폰트만 시스템 폰트로 대체) 터치 화면(전자칠판·태블릿)에서도 사용할 수 있습니다.

## 화면 구성
- **예약판(메인):** 자원 칩, 주 내비, 자원 정보, 요일×교시 격자(블록·차단·휴업·수량 잔여), 요약(이번 주 예약·빈 교시·미확인 링크)과 범례, '정기 예약'·'인쇄' 버튼.
- **예약 모달:** 자원·날짜·시작/끝 교시·학급(담임 자동)·교사·활동 태그 8종·수량(수량형)·메모, 검증 영역(녹/적/황), 대안 칩, 지난 예약의 사용 여부 토글, 시리즈 안내, 저장·삭제·취소.
- **학사일정:** 월간 달력(유형별 색 점, 학기 밖 흐림, 오늘 강조), 일정 목록(충돌 n건 버튼·수정·삭제), 일정 모달(차단 자원·교시 선택, 충돌 예약 수 실시간 표시).
- **자원:** 자원 카드(색 띠·유형·수량·그룹·담당·수용·교시·활성 스위치), 자원 모달(팔레트 8색·교시 체크·우선 규칙), 학급 표·교사 표.
- **통계:** 기간·자원 필터, 요약 카드 4개, SVG 차트 4종, 이용 저조 학급 목록, '실적 보고 인쇄'·'집계 CSV 내보내기'.
- **설정:** 학교·학기 정보, 결재란, 교시 구조(4~10개, 범위 밖 예약 시 변경 차단), JSON/CSV 입출력(드롭존), 새 학기 초기화, 샘플 복원, 운영 방법 안내.
- **인쇄 미리보기 모달:** 종이 모양 미리보기(A4 가로/세로), 출력 범위 옵션, '브라우저 인쇄'.

## 사용 방법
1. **자원 고르기** — 예약판 상단 칩에서 자원을 선택하고 ◀ ▶·'이번 주'·날짜 입력으로 주를 이동합니다.
2. **예약하기** — 빈 셀을 클릭(1교시)하거나 같은 요일에서 아래로 드래그(연속 교시)하면 모달이 열립니다. 학급을 고르면 담임이 자동 입력되고, 겹치면 빨간 사유와 대안 칩이 나타납니다. 칩을 누르면 폼이 바뀌고 다시 검증됩니다.
3. **정기 예약** — '정기 예약'에서 요일·교시·기간을 넣고 미리보기로 휴업일 제외·충돌을 확인한 뒤 생성합니다. 시리즈 블록 삭제 시 범위를 고릅니다.
4. **학사일정** — 공휴일·재량휴업일은 전체 자원을, 학교행사는 지정 자원·교시를 차단합니다. 저장 시 충돌 예약 수를 알려 주고 목록에서 수정·삭제할 수 있습니다.
5. **통계·보고** — 자원별 가동률, 학급×자원 형평성 히트맵('저조'), 요일×교시 혼잡도를 보고 '실적 보고 인쇄'로 A4 보고서를 출력합니다. 지난 예약은 '실제 사용함/사용 안 함'을 체크합니다.
6. **인쇄·보관** — 예약판 '인쇄'로 주간 이용 현황표(A4 가로·결재란)를 출력하고, 설정 탭에서 JSON 내보내기/가져오기·CSV·새 학기 초기화를 합니다.
- 팁: 모달은 Esc로 닫고, 격자 빈 셀은 Tab으로 이동해 Enter로 예약할 수 있습니다. 헤더의 달 아이콘으로 라이트/다크 테마를 바꿉니다.

## 데이터 저장·내보내기·가져오기
- 모든 변경은 즉시 localStorage 키 `srb.v1.data`에 저장됩니다(`{meta, settings, resources, classes, teachers, events, series, bookings}`). 마지막 탭·자원·주차·통계 기간은 `srb.v1.ui`, 온보딩 여부는 `srb.v1.onboarded`, 테마는 `edu.special-room-booking.theme`에 저장됩니다.
- 저장이 불가능하면(사생활 모드·용량 초과) 상단에 '메모리 모드' 배너가 뜨고 앱은 계속 동작합니다.
- **JSON 내보내기:** `special-room-booking_YYYYMMDD.json`(전체 백업). **가져오기:** 파일 선택 또는 드롭존에 드래그 → 스키마 검증 → '교체' 또는 '병합(같은 id는 수정 시각이 최신인 쪽 유지, 병합 후 초과 예약 재검사)'.
- **CSV:** 예약 목록(날짜·요일·교시·자원·학급·교사·태그·수량·사용여부·메모)과 통계 집계표를 UTF-8 BOM으로 내보내 엑셀에서 바로 열립니다.
- **새 학기 초기화:** 확인 모달에 '초기화'를 입력해야 실행되며 예약·시리즈·일정만 삭제하고 자원·학급·교사·설정은 유지합니다.

## 샘플 데이터 안내
내장 샘플은 **가상의 가온초등학교 2026학년도 2학기(9/1~12/31)** 입니다. 자원 10개(공간형 7: 과학실1·2, 컴퓨터실, 강당, 시청각실, 영어체험실, 음악실 / 수량형 3: 태블릿 세트 2, 이동식 빔프로젝터 3, 과학 탐구 교구 세트 4), 학급 18개(1-1~6-3)와 담임 18명 + 전담 5명, 학사일정 10건, 정기 예약 시리즈 10개와 단건 예약을 합쳐 약 220건이 들어 있습니다. 교사 이름은 모두 가명이며 공통 샘플 담임 '이가람'은 5-2 담임입니다. 이 앱은 학생 개인 데이터를 다루지 않습니다. 시연 포인트: 태블릿 세트 10/20(화) 3교시 '2/2 사용 중', 빔프로젝터 10/21 4교시 3/3, 강당의 운동회 연습·학예회 리허설 기간 '충돌' 배지, 5-3의 과학실 이용 '저조'.

## 기술적 특징
- **교시 단위 충돌 검사 하나로 공간형·수량형 통일:** `checkConflict(resource, date, pStart, pEnd, qty)`가 학기 범위 → 주말 → 휴업일 → 행사 차단 → 교시별 사용량(공간형은 ≥1, 수량형은 사용량+요청 > 보유) → 사용 불가 교시 → 우선 학년 규칙(경고) 순으로 검사하고 `{ok, reasons, warnings, conflictBookings, remaining}`을 돌려줍니다. 정기 예약 전개, 샘플 생성, 대안 추천(같은 날 거리순 교시 → 같은 그룹 자원 → 같은 주 요일)이 모두 이 함수를 재사용합니다. 예약은 `${resourceId}|${date}` Map으로 인덱싱해 주간 렌더와 검사를 O(1) 조회로 처리합니다.
- **Pointer Events 드래그와 SVG 통계:** 격자는 CSS Grid div 셀(data-day/data-period)이고 pointerdown→pointermove(elementFromPoint)→pointerup으로 같은 열의 연속 범위를 선택하며, 예약·차단 셀을 만나면 직전 유효 범위에서 멈춥니다(5px 미만은 클릭). 통계는 `computeStats`가 수업일·차단 교시를 반영한 가용 교시, 학급×자원 행렬과 학년 평균(50% 미만 '저조'), 요일×교시 혼잡도를 한 번에 계산하고 SVG 문자열 함수 4개가 렌더합니다.
- 테스트·디버그용으로 `window.__app = { version, getState(), actions: {...} }`를 노출합니다(읽기 전용 상태 스냅샷 + 탭/자원/주 이동, 충돌 검사, 예약 추가·삭제, 통계, 샘플 복원, 가져오기 등).

## 제한 사항 및 향후 개선
- 여러 PC 간 실시간 동기화·동시 편집, 로그인·권한 분리, 알림 발송, 나이스·K-에듀파인 연동은 지원하지 않습니다(공용 PC 운영 또는 JSON 공유로 대체).
- 분 단위 시간제 대관·주말 예약·외부 대관, 기자재 대여·반납 상태 추적은 범위 밖입니다.
- 예약 블록을 끌어 다른 셀로 옮기는 드래그 이동은 구현하지 않았습니다(블록 클릭 → 수정 모달에서 날짜·교시 변경).
- 향후: 학년도 간 비교 통계, 자원별 담당자 메모 이력, 교무실 전자칠판용 전체 자원 한눈에 보기 화면.

## 바이브코딩 개발 과정
1. 교무실 화이트보드 예약판의 문제(이중 예약·행사 날 예약·수량 기자재 소재 불명·학기말 수작업 집계)를 정리하고 AI에게 "요일×교시 격자 + 교시 단위 충돌 검사 + 형평성 히트맵"이라는 핵심 가치를 가진 앱 스펙을 요청했습니다.
2. 공통 규약(순수 HTML/CSS/JS, file:// 실행, alert 금지, 테마 토큰, localStorage 래퍼)을 먼저 읽게 한 뒤 데이터 모델(settings/resources/classes/teachers/events/series/bookings)과 알고리즘(checkConflict, suggestAlternatives, expandSeries, computeStats)을 먼저 확정했습니다.
3. "공간형과 수량형을 같은 충돌 알고리즘으로 처리하라", "샘플 시리즈는 하드코딩 대신 실제 전개 함수로 만들어라"처럼 구조를 단순하게 유지하는 프롬프트로 코드량을 2,500줄 안팎으로 관리했습니다.
4. 격자 드래그는 Pointer Events(setPointerCapture, elementFromPoint)로, 차트는 SVG 문자열로, 인쇄는 #print-root와 @media print로 구현하도록 지시하고 모바일(640px 미만) 요일 탭 분기를 추가했습니다.
5. Playwright 스모크 점검(콘솔 오류·가로 스크롤·3개 뷰 스크린샷)과 수용 기준 13개를 자동 테스트로 확인하며 발견된 문제를 고쳤습니다.
6. 마지막으로 README·도움말·온보딩 문구를 현장 교사가 읽는 말투로 다듬고 샘플 데이터(가온초 5-2 담임 이가람 포함)를 공통 샘플과 맞췄습니다.
