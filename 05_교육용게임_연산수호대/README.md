# 연산수호대 — 답을 입력해 쏘는 연산 타워 디펜스, 틀린 문제는 '복수 몬스터'로 다시 돌아온다
**카테고리:** 05. 교육용 게임 앱  |  **대상:** 초등 1~6학년 학생(개인 플레이), 담임·수학 교과 교사(설정·프로필·기록 관리)  |  **기술:** HTML/CSS/JS (외부 라이브러리 없음)

## 소개
연산 반복 연습은 꼭 필요하지만 지루합니다. 연산수호대는 1~6학년 교육과정의 연산 영역(덧셈·뺄셈·곱셈구구·나눗셈·분수·소수·비율)을 실시간 타워 디펜스 위에 올려 "성을 지키는 한 판"으로 바꿉니다. 문제를 머리 위에 단 몬스터가 성으로 다가오고, 학생이 정답을 입력하면 포탑이 그 몬스터를 자동 조준해 격파합니다. 콤보·성 HP·웨이브·보스·별·배지·스킨 해금이 동기를 유지하는 동안, 틀린 문제는 즉시 시각 모델 교정 카드로 바로잡고 '복수 몬스터'와 약점 큐로 다시 출제되어 학생별 취약 연산을 자동으로 더 연습하게 됩니다. 문제는 전부 규칙으로 생성되고 효과음은 Web Audio로 합성하므로 index.html 하나로 서버·로그인·외부 파일 없이 동작합니다.

## 실행 방법
- `index.html`을 더블클릭하면 바로 실행됩니다(file:// 지원, 네트워크 불필요. Google Fonts만 선택적으로 로드).
- 로컬 서버로 열어도 동일하게 동작합니다(예: `npx serve`).
- 권장 브라우저: 최신 Chrome / Edge. 태블릿·전자칠판 터치 지원(키패드 56px 이상). 효과음은 첫 터치·키 입력 이후 재생됩니다.

## 화면 구성
- **홈·스테이지 맵**: 프로필 드롭다운·새 프로필·체험하기, 프로필 요약(총 별·배지·약점 문제·스킨), 학년 탭, 스테이지 카드(최고 점수·별·잠금/닫힘).
- **게임 화면**: Canvas(16:9) + HUD(점수·콤보·하트·웨이브·남은 시간·필살기 게이지·음소거·일시정지·전체화면) + 입력 패널(키패드/소수점/3지선다). 900px 이하에서는 위아래 배치, 입력 패널 하단 고정.
- **결과·복습 화면**: 클리어/게임 오버/시간 종료/중단 라벨, 점수 카운트업, 별 팝인, 통계 6종, 새 배지·해금 알림, 틀린 문제 카드(정답·한 줄 풀이·상자), 다시 풀기·다시 도전·다음 스테이지.
- **도감**: 2-3 곱셈구구 72칸 히트맵(칸 클릭 툴팁), 다른 스테이지 약점 목록·숙달 진행 막대, 배지 격자, 포탑 스킨·배경 테마 선택.
- **명예의 전당**: 점수/별/성장 탭, 스테이지 드롭다운, 순위표, 기록표 인쇄·CSV.
- **선생님 설정**: 게임 설정, 프로필 관리 표, 데이터(백업·가져오기·CSV·초기화), 저장 상태.

## 사용 방법
1. 상단에서 **내 프로필**을 고르거나 **새 프로필**을 만듭니다. 이름 없이 **체험하기**도 가능합니다(기록 저장 안 됨).
2. 학년 탭에서 스테이지 카드의 **시작**을 누릅니다. 이전 스테이지를 별 1개 이상으로 클리어하면 다음이 열립니다.
3. 몬스터 머리 위 문제의 답을 **키패드로 입력하고 발사(Enter)** 하면 포탑이 자동 조준해 격파합니다. 3지선다 스테이지는 1·2·3 버튼으로 고릅니다.
4. 틀리면 **교정 카드**에서 그림으로 다시 생각하고 정답을 입력합니다. 틀린 문제는 **복수 몬스터**로 돌아오므로 꼭 복수하세요(점수 2배).
5. 콤보를 이어 배율을 올리고, 콤보 10마다 **필살기(Space)** 가 충전됩니다. 10웨이브 보스의 방패 3개를 깨면 클리어!
6. 결과 화면의 **다시 풀기**로 틀린 문제를 복습하고, **도감·명예의 전당**에서 숙달·배지·랭킹을 확인합니다.
- 단축키: 숫자·Enter·Backspace·'.'(소수) · Space 필살기 · Esc 일시정지 · 1/2/3 선택지. 선생님은 ⚙에서 스테이지·속도·시간 제한·랭킹 공개·프로필·백업을 관리합니다.

## 데이터 저장·내보내기·가져오기
- 모든 상태는 localStorage 키 `mathGuardians.v1` 하나에 JSON(schemaVersion 1)으로 300ms 디바운스 저장됩니다. 게임 중에는 저장하지 않고 결과 확정 시 1회 기록합니다.
- localStorage가 차단되거나 가득 차면 메모리로 계속 동작하며 상단에 '저장 불가' 경고 배지가 표시됩니다. 저장 데이터가 손상되면 원본을 `mathGuardians.v1.corrupt`로 보관한 뒤 샘플로 재시딩합니다.
- 선생님 설정 > 데이터: **JSON 백업**(`math-guardians-backup-YYYYMMDD.json`), **JSON 가져오기**(파일 선택 또는 드롭 → 구조 검증 → '현재 데이터를 덮어씁니다' 확인), **기록 CSV**·**약점 문제 CSV**(UTF-8 BOM), **명단 CSV 가져오기**('번호,이름'), **샘플 데이터로 초기화**(확인 모달).
- 테마 선택값은 `edu.math-guardians.theme`, 마지막 학년 탭·랭킹 탭은 `mathGuardians.ui`에 저장됩니다.

## 샘플 데이터 안내
내장 데이터는 모두 **가상**입니다. 가온초등학교 5학년 2반(담임 이가람) 학생 24명 프로필이 첫 실행 시 자동 시딩되며, 그중 김하늘·이도윤·박서아·최민준·정하윤·한수아 6명에게만 기록·배지·약점 문제가 있습니다(연산 복습 목적의 저학년 스테이지 기록 위주). 날짜는 시딩 시점 기준 상대값으로 생성되어 언제 열어도 7일 연속 배지·성장 랭킹이 성립합니다.

## 기술적 특징
- **Canvas 게임 루프**: 논리 해상도 960×540을 CSS aspect-ratio로 맞추고 DPR(최대 1.5)만큼 백버퍼를 키워 선명하게 그립니다. rAF 루프는 dt를 50ms로 제한해 탭 전환 후 순간이동을 막고, 상태 플래그(playing/card/resume/paused/ended)로 교정 카드·일시정지를 처리합니다. 파티클(상한 120, 저사양 40)·플로팅 텍스트·흔들림·플래시는 배열을 재사용하며 shadowBlur를 쓰지 않습니다.
- **Web Audio 합성 효과음**: 오디오 파일 없이 Oscillator/노이즈 버퍼 + Gain 엔벨로프로 발사·명중·콤보(반음 상승)·버저·피격·보스 드럼·웨이브 클리어·팡파르·필살기 스윕을 만듭니다. AudioContext는 첫 pointerdown/keydown에서 생성·resume하고 동시 노드 16개로 제한합니다.
- **학습 엔진**: 문제는 `{op, a, b…}` 매개변수로 표현되어 같은 사실을 언제든 재생성할 수 있습니다(복수 몬스터·약점 큐·복습·보스 방패). 사실별 숙달 상자(0~3)는 정답 +1, 오답 0, 미응답 −1로 갱신되고 상자 2 미만은 다음 판 스폰의 20%를 차지합니다. 소수는 정수 스케일(×10/×100), 분수는 gcd 기약분수로 계산해 부동소수점 오차가 없습니다.
- **적응형 난이도**: 최근 10문항의 정답률과 반응시간 비율로 속도 배수(0.7~1.5)와 동시 출현 수를 조정합니다.
- 테스트 용이성을 위해 `window.__app = { version, getState(), actions: {...} }`(읽기 전용 상태 스냅샷 + 주요 액션)를 노출합니다.

## 제한 사항 및 향후 개선
- 1인 플레이 전용이며 멀티플레이·서버 저장·기기 간 동기화는 없습니다(JSON 백업으로 이동).
- 분수 스테이지는 3지선다로 한정되고 문장제·혼합 계산·소수 셋째 자리 연산은 다루지 않습니다.
- 문제 범위는 프리셋 스테이지 단위로만 조절할 수 있습니다. 향후 교사용 범위 커스터마이즈, 음성 안내, 모둠 대결 모드를 검토할 수 있습니다.

## 바이브코딩 개발 과정
1. 카테고리 5(교육용 게임)에 맞는 6개 아이디어를 AI와 비교 채점해 "연산 디펜스 코어 루프 + 사실 단위 학습 엔진"을 결합한 연산수호대로 확정했습니다.
2. 5개 앱 공통 규약(file:// 실행, 외부 라이브러리 금지, 테마 토큰, 모달·토스트, 저장 규칙)을 먼저 정리하고 스펙(기능·화면·데이터 모델·알고리즘 A1~A14·수용 기준)을 JSON으로 작성했습니다.
3. "스테이지별 문제 생성 규칙과 3지선다 오답 규칙을 코드로" 프롬프트로 problems.js를 만들고 Node에서 스테이지마다 300회 생성해 정답·선택지 유효성을 검증했습니다.
4. Canvas 루프·조준·웨이브·보스·필살기와 Web Audio 효과음을 game.js/audio.js로 분리해 구현하고, 교정 카드 시각 모델 5종을 DOM 애니메이션으로 추가했습니다.
5. 공통 샘플 데이터(가온초 5-2, 24명)를 시딩 함수로 내장하고 명예의 전당·도감 수용 기준(점수 순서, 8×7 빨간 칸)이 성립하도록 수치를 맞췄습니다.
6. 정적 점검(lint)과 Playwright 스모크·수용 테스트(34개 이상 항목: 12초 도달 시간, 복수 몬스터, 보스 클리어, JSON 복원, 400px 가로 스크롤, localStorage 차단)를 돌려 발견된 문제를 고친 뒤 README를 정리했습니다.
