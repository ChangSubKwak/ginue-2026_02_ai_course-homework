# 연산수호대

연산 문제의 답을 입력해 몬스터를 막는 **연산 타워 디펜스 게임**입니다. 틀린 문제는 '복수 몬스터'로 다시 돌아옵니다.

- **카테고리**: 05. 교육용 게임 앱
- **대상**: 초등 1~6학년 학생(아침활동·마무리 5분·보충학습), 담임·수학 교사
- **기술**: HTML · CSS · JavaScript (Canvas 게임, Web Audio 효과음, 외부 라이브러리 없음)

## 실행 방법

`index.html`을 더블클릭하면 브라우저(Chrome·Edge 권장)에서 바로 열립니다. 설치나 인터넷 연결이 필요 없습니다. 효과음은 첫 클릭 이후 재생됩니다.

온라인: https://changsubkwak.github.io/ginue-2026_02_ai_course-homework/05_교육용게임_연산수호대/

## 할 수 있는 것

- **학년별 스테이지**: 1~6학년 덧셈·뺄셈·곱셈구구·나눗셈·분수·소수·비율 19개 스테이지. 문제는 매번 새로 생성
- **게임 요소**: 점수·콤보 배율·성 체력·웨이브·10웨이브 보스·별 1~3개·필살기
- **오답 교정**: 틀리면 점 배열·세로셈·분수 막대 그림으로 풀이를 보여 주고, 틀린 문제는 점수 2배 '복수 몬스터'로 다시 출제
- **기록**: 학생 프로필별 최고 점수·별·배지, 숙달 도감, 명예의 전당(점수·별·성장)
- **선생님 설정**: 스테이지 열기/닫기, 속도·시간 제한, 랭킹 공개 여부, 프로필 관리, 백업

## 사용 순서

1. 내 프로필을 고르거나 **체험하기**를 누릅니다.
2. 학년 탭에서 스테이지를 시작합니다.
3. 몬스터 머리 위 문제의 답을 키패드로 입력하고 **발사(Enter)** 합니다.
4. 틀리면 교정 카드로 다시 풀고, 결과 화면의 **다시 풀기**로 복습합니다.

단축키: 숫자·Enter·Backspace, Space 필살기, Esc 일시정지

## 파일

```
index.html        화면 뼈대
css/style.css     스타일(라이트/다크, 반응형, 인쇄)
js/data.js        스테이지·배지·샘플 데이터
js/problems.js    문제 생성기·한 줄 풀이
js/audio.js       Web Audio 효과음
js/game.js        Canvas 게임 루프
js/ui.js          홈·결과·도감·설정 화면
js/app.js         시작·저장·화면 전환
```
