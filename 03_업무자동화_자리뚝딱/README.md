# 자리뚝딱

조건만 체크하면 **자리표·모둠·역할을 자동으로 만들어 주는** 담임 교사용 자리 배치 도우미입니다.

- **카테고리**: 03. 학교 업무 자동화 앱
- **대상**: 초등학교 담임교사(학생은 TV 발표 모드로 함께 봄)
- **기술**: HTML · CSS · JavaScript (외부 라이브러리 없음)

## 실행 방법

`index.html`을 더블클릭하면 브라우저(Chrome·Edge 권장)에서 바로 열립니다. 설치나 인터넷 연결이 필요 없습니다.

온라인: https://changsubkwak.github.io/ginue-2026_02_ai_course-homework/03_업무자동화_자리뚝딱/

## 할 수 있는 것

- **학급 명렬**: 번호·이름·성별·배려 태그(앞자리 필요 등) 관리, 엑셀 붙여넣기·CSV 등록
- **교실 레이아웃**: 2인 짝 분단형·4인 모둠형·ㄷ자형·1인 시험형, 책상 켜기/끄기
- **자동 배치**: "앞자리 필요 학생은 앞쪽", "이 둘은 떨어뜨리기", "남녀 짝", "최근 짝 피하기" 등 조건을 지키는 좌석표를 1초 안에 생성. 못 지킨 조건은 리포트로 보여 줌
- **수동 조정**: 드래그나 탭-탭으로 자리 교환, 되돌리기(Ctrl+Z)
- **모둠·역할**: 성별·수준 균형 모둠 편성, 역할을 돌아가며 배정
- **발표 모드**: TV에서 카드가 한 장씩 뒤집히며 자리 공개
- **인쇄 4종**: 학생 게시용 자리표, 교사용 자리표(180° 회전), 모둠 명단, 책상 명패
- **공정성 확인**: 누가 누구와 몇 번 앉았는지 히트맵, 앞·뒤 자리 편중 확인

## 사용 순서

1. 명렬 탭에서 학생과 배려 태그를 확인합니다.
2. 자리 배치 탭에서 레이아웃과 지킬 조건을 고릅니다.
3. **자동 배치**를 누르고, 필요하면 드래그로 조정합니다.
4. 발표 모드로 공개한 뒤 **배치 확정**하고 인쇄합니다.

## 파일

```
index.html      화면
css/style.css   스타일(라이트/다크, 반응형, 인쇄)
js/data.js      샘플 학급·기본 설정
js/engine.js    자동 배치·모둠 편성 알고리즘
js/ui.js        모달·토스트·드래그 공통 함수
js/app.js       화면 구성·저장·인쇄·발표 모드
```

## 참고

- 내장 학급(경인초등학교 5학년 2반, 학생 25명)은 모두 가상입니다.
- 데이터는 이 브라우저(localStorage)에만 저장되며, 설정 탭에서 JSON으로 백업·복원할 수 있습니다. 공용 PC에서는 사용 후 '전체 데이터 삭제'를 권장합니다.
