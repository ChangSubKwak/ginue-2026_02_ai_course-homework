# 자리뚝딱 — 조건만 체크하면 자리표·모둠·역할이 30초 만에 완성되는 담임 교사용 자리 배치 도우미

**카테고리:** 03. 학교 업무 자동화 앱  |  **대상:** 초등학교 담임교사(1~6학년), 교과 전담·중학교 담임도 사용 가능, 학생은 TV 발표 모드로 함께 보는 간접 사용자  |  **기술:** HTML/CSS/JS (외부 라이브러리 없음)

## 소개
담임교사는 월 1회꼴로 자리를 바꾸고 프로젝트·실험 수업마다 모둠을 다시 짜면서 "시력 나쁜 아이는 앞자리", "이 둘은 떨어뜨리기", "남녀 짝", "지난번 짝은 피하기" 같은 조건을 머릿속으로 동시에 맞추느라 회당 30분 이상을 씁니다. 자리뚝딱은 명렬과 조건 체크만 입력받아 제약 만족 알고리즘(패널티 언덕 오르기)으로 자리표·모둠표·역할표를 자동 생성하고, 충족하지 못한 조건은 리포트와 빨간 테두리로 투명하게 보여 줍니다. 드래그 또는 탭-탭으로 미세 조정한 뒤 학생 게시용·교사용(교탁 기준 180° 반전) 자리표와 책상 명패를 한 번에 인쇄할 수 있고, 배치 이력이 쌓이면 "누가 누구와 몇 번 앉았는지", "누가 늘 뒷자리였는지"를 히트맵으로 확인해 학급 운영의 공정성을 설명할 수 있습니다. 전체 화면 발표 모드는 학생들에게 "컴퓨터가 공정하게 뽑았다"는 공개 절차를 제공합니다.

## 실행 방법
- `index.html`을 더블클릭하면 바로 실행됩니다(file:// 환경, 설치·서버 불필요).
- 로컬 서버로 열어도 동일하게 동작합니다. 예: `python -m http.server` 후 `http://localhost:8000/index.html`
- 권장 브라우저: 최신 Chrome / Edge. 전자칠판·태블릿 터치를 지원합니다(터치 타깃 44px, 탭-탭 교환).
- 인터넷이 없으면 Google Fonts(Do Hyeon·IBM Plex Sans KR) 대신 시스템 글꼴로 표시되며 기능은 동일합니다.

## 화면 구성
- **공통 프레임**: 상단 바(앱 이름, 학급명 편집, 저장 상태 점, 인쇄·발표 모드·테마·도움말), 탭 5개(명렬/자리 배치/모둠/히스토리/설정, 좌우 화살표 키로 이동). 600px 이하에서는 탭이 하단 고정 아이콘 바로 바뀌고 교실·조건 패널은 접힌 채 시작합니다. 토스트는 하단 중앙(같은 문구는 하나로 합침, 최대 3개).
- **명렬 탭**: 요약 칩(활성 n명·태그별 인원), '다음: 자리 배치' 버튼, 학생 표, 붙여넣기 등록(미리보기 표), CSV 드롭존, 분리·결합 쌍 목록.
- **자리 배치 탭**: 좌측 교실·조건 패널(아코디언), 중앙 버튼 행 + 좌석표(칠판 띠, 카드, 확대/축소 슬라이더·맞춤 버튼, 구역·태그 범례) + 미배치 목록(배치가 있거나 레이아웃 변경으로 좌석을 잃었을 때 표시), 우측 충족 리포트와 완화 제안.
- **발표 모드 오버레이**: 대형 좌석표(뒷면 '?'), 하단 바(시작/일시정지·다음 한 장·전체 공개·순서·소리·종료), 진행 표시 'k/n 공개'.
- **모둠 탭**: 옵션 바, 색 띠 모둠 카드(멤버 칩·역할 배지·편차 경고), 편성 리포트.
- **히스토리 탭**: 필터 칩(전체/자리/모둠), 기록 카드, 공정성 대시보드(히트맵·구역 막대·역할 표).
- **인쇄 미리보기**: 인쇄하기/닫기 버튼(상단, 좁은 화면에서는 고정), 종류 라디오 4종, 옵션 체크, A4 비율 미리보기(페이지 분할).
- **설정 탭**: 역할 목록, 모둠 이름·색, 기본 회피 횟수·플립 간격·소리, 백업(내보내기/가져오기/샘플/삭제), 공용 PC 주의 안내, 버전·저장 용량.

## 사용 방법
처음 실행하면 3단계 안내 투어가 한 번 표시됩니다(건너뛰어도 다시 뜨지 않으며, '다시 보지 않기'를 끄면 다음 실행 때 다시 볼 수 있고 상단 '?' 도움말에서도 다시 열 수 있습니다).
1. **명렬 확인**: 명렬 탭에서 학생 번호·이름·성별과 배려 태그를 확인합니다. 전출·장기결석 학생은 비활성으로 두면 배치에서 빠집니다. 엑셀에서 '번호 이름 성별' 열을 복사해 붙여넣고 인식 → 추가하면 일괄 등록됩니다.
2. **조건 체크**: 자리 배치 탭 왼쪽에서 프리셋·수치를 고르고(편집 모드로 책상 켜기/끄기), 조건 패널에서 지킬 조건과 하드/소프트를 정합니다. 떨어뜨릴 짝·붙일 짝은 명렬 탭에서 등록합니다.
3. **자동 배치**: 자동 배치를 누르면 1초 안에 좌석표가 완성되고 충족 리포트가 조건별 결과를 보여 줍니다. 위반이 남으면 완화 제안을 따르거나 다시 섞기를 누르세요. 자물쇠를 켠 학생은 자리를 지킵니다.
4. **미세 조정**: 카드를 드래그하거나 두 카드를 차례로 탭하면 교환됩니다(키보드: Tab으로 카드·빈 책상 이동, Enter/Space로 선택). 새 위반은 토스트로 알려 주며 자리 배치 탭에서 Ctrl+Z/Ctrl+Y로 되돌립니다.
5. **발표·확정·인쇄**: 발표 모드에서 TV로 카드를 한 장씩 뒤집어 공개하고(Space=다음, Esc=종료), 배치 확정으로 히스토리에 저장한 뒤 인쇄에서 게시용·교사용·명패를 출력합니다.
6. **모둠·공정성**: 모둠 탭에서 모둠 수(또는 인원)와 옵션을 정해 편성하고 역할 배지를 확인합니다. 히스토리 탭의 히트맵·구역 막대로 공정성을 점검합니다.

## 데이터 저장·내보내기·가져오기
- 모든 데이터는 브라우저 `localStorage`(키 `edu.jari-ttukttak.data`, UI 상태 `edu.jari-ttukttak.ui`, 테마 `edu.jari-ttukttak.theme`)에만 저장되며 서버로 전송되지 않습니다. 변경 300ms 후 자동 저장되고 상단 바의 저장 상태 점이 결과를 표시합니다.
- 저장소를 사용할 수 없으면(차단·용량 초과) 메모리 모드로 계속 동작하고 노란 배너로 JSON 내보내기를 권고합니다.
- **JSON 내보내기**: 설정 탭에서 전체 데이터를 `jari-ttukttak-YYYYMMDD.json`으로 다운로드합니다. **가져오기**: 파일 선택 또는 드롭 → 구조 검증(최상위 키와 학생·쌍·레이아웃·히스토리 항목) → 요약(학생 n명·배치 k건) 확인 모달 → 덮어쓰기. 손상된 파일·version 불일치·항목 누락은 거부하고 기존 데이터를 유지합니다(화면 표시 중 오류가 나도 저장하지 않고 되돌립니다).
- **자리표 PNG**: 배치 탭 '이미지 저장'으로 `jari-YYYYMMDD.png`를 내려받아 알림장·교실 게시에 활용합니다.
- 공용 PC에서는 사용 후 '전체 데이터 삭제'(2단계 확인)를 권장합니다. 삭제 후에는 새로고침해도 빈 학급이 유지되며, 샘플은 '샘플 데이터 다시 불러오기' 버튼으로만 돌아옵니다.

## 샘플 데이터 안내
내장된 **가온초등학교 5학년 2반(담임 이가람)** 은 가상의 학교·학급이며 학생 25명(공통 샘플 24명 + 전출 처리 시연용 25번 백건우 비활성)의 이름도 모두 가상입니다. 태그(앞자리 필요 3명·집중 지원 2명·키 큼 3명), 분리 하드 2쌍·결합 소프트 1쌍, 2인 짝 분단형 3분단×5열(뒷줄 양끝 2책상 끔) 레이아웃, 배치 히스토리 4건(이도윤-한수아 3회 연속 짝, 양은우 4회 중 3회 뒤 구역 → 히트맵·편중 주의 시연)과 모둠 히스토리 1건(과학 실험 6모둠)이 들어 있습니다. 현재 배치는 비어 있어 '자동 배치' 한 번으로 체험이 시작됩니다. 설정 탭의 '샘플 데이터 다시 불러오기'로 언제든 복원할 수 있습니다.

## 기술적 특징
- **제약 만족 자동 배치 엔진(패널티 언덕 오르기)**: 배치의 패널티 P = Σ(가중치 × 위반 수)로 정의합니다(하드 1000, 분리 쌍 인접 50, 결합 쌍 비인접 50, 앞자리 40, 집중 지원 30, 키 큼 20, 같은 성별 짝 10, 최근 N회 같은 짝 15×횟수, 같은 좌석 5). 핀 고정 학생을 먼저 두고 나머지를 셔플해 놓은 뒤 두 자리를 무작위로 교환하며 P가 줄면 유지하는 언덕 오르기를 2,000회(200회 연속 개선 없으면 종료) 수행하고, 이를 최대 30회 랜덤 재시작(전체 800ms 상한)해 최소 P 배치를 채택합니다. 같은 평가 함수가 상세 모드로 조건별 리포트·위반 좌석·완화 제안(예: 앞 구역 책상 부족 n>m)을 만듭니다. 모둠 편성도 같은 방식(수준 내림차순·성별 교대 정렬 → 뱀 분배 → 교환 언덕 오르기)이며, 역할은 과거 경험 횟수가 가장 적은 학생에게 우선 배정합니다.
- **Pointer Events 드래그앤드롭 + 교사용 반전 인쇄**: 마우스·터치를 `pointerdown/move/up` + `setPointerCapture`로 공통 처리하고 `elementFromPoint`로 드롭 대상 책상을 판정합니다(이동 5px 미만이면 탭으로 간주해 탭-탭 교환). 교사용 자리표는 격자를 행·열 역순으로 180° 회전해 칠판 띠를 아래에 그리며, 명패는 A4 세로 한 장에 접이식 4개로 자동 분할됩니다. 히트맵·구역 막대는 인라인 SVG, PNG는 Canvas 2D로 생성합니다.
- 테스트·디버그용으로 `window.__app = { version, getState(), actions: {...} }`를 노출해 읽기 전용 상태 스냅샷과 주요 액션(자동 배치·교환·되돌리기·모둠 편성·발표·인쇄·백업)을 콘솔이나 자동화 도구에서 호출할 수 있습니다.

## 제한 사항 및 향후 개선
- 학급은 1개만 관리합니다(다른 학급은 JSON 내보내기/가져오기로 전환). 서버·로그인·클라우드 동기화는 없습니다.
- 교실 편집은 프리셋 4종 + 책상 켜기/끄기로 한정되며 자유 좌표 배치는 지원하지 않습니다. ㄷ자형은 교탁을 향해 열린 모양 한 가지입니다.
- 엑셀(.xlsx) 직접 읽기·PDF 직접 생성은 지원하지 않고 CSV·붙여넣기와 브라우저 인쇄를 사용합니다. 1인 1역 주간 로테이션표는 미구현(향후 과제)입니다.
- 향후: 1인 1역 로테이션표, 좌석표 템플릿 공유, 더 많은 레이아웃(원형·토론형), 학기 단위 공정성 리포트 PDF.

## 바이브코딩 개발 과정
1. 담임교사의 자리 배치 업무를 인터뷰하듯 정리해 "조건 체크 → 자동 배치 → 공개 → 인쇄 → 이력"의 사용자 흐름과 must/should/nice 기능 목록을 AI와 함께 스펙(JSON)으로 확정했습니다.
2. 유사 아이디어 3안(자리뚝딱·자리요정·자리마법사)을 심사 기준(가치·실용·구현·임팩트·적합)으로 비교해 장점을 합치고, 규모 통제를 위해 레이아웃 편집을 프리셋 4종으로 제한하는 결정을 내렸습니다.
3. 공통 규약(순수 HTML/CSS/JS, file:// 실행, 테마 토큰, alert 금지, localStorage 래퍼, 샘플 데이터 내장)을 먼저 읽고 data.js → engine.js → ui.js → app.js → style.css 순으로 AI에게 모듈별 구현을 요청했습니다.
4. 엔진은 "패널티 함수와 언덕 오르기 의사코드"를 프롬프트로 주고, 리포트·완화 제안이 같은 평가 함수에서 나오도록 구조를 지시했습니다.
5. Playwright 수용 테스트 모듈(64개 체크)을 작성해 자동 배치 시간, 위반 토스트, Ctrl+Z, 핀 고정, 발표 모드 플립 간격, 모둠 역할, 인쇄 반전, 새로고침 복원, JSON 왕복, 400px 탭-탭을 브라우저에서 검증했습니다.
6. 테스트에서 드러난 문제(레이아웃 변경 시 배치 잔류, 렌더 중 중첩 change 이벤트 예외, 축소 시 자물쇠 버튼이 카드 중앙을 덮는 문제)를 AI와 원인 분석 후 수정하고 lint·스모크 점검 0건을 확인한 뒤 README를 정리했습니다.
7. 기능 테스트·코드 리뷰·UX 리뷰 3개 검증 보고서의 결함(교사용 180° 자리표 격자 붕괴, 손상 JSON 가져오기, 확정 직후 자기 자신과 비교되는 리포트, ㄷ자형 20석 상한, 전체 삭제 후 샘플 복귀, 조건 라벨 줄바꿈·명렬 표 잘림 등)을 심각도 순으로 수정하고 기존 테스트 모듈 전체를 재실행해 통과시켰습니다.
